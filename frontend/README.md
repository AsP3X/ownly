# Ownly frontend

← [Back to main README](../README.md) · [Documentation index](../docs/README.md)

Vite + React + TypeScript web app for Ownly.

## Develop

```bash
npm install
npm run dev
```

Vite proxies `/api/v1` to `http://localhost:3000`. Full stack setup: [Getting started](../docs/getting-started.md) · [Local development](../docs/local-development.md).

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Dev server with HMR |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm run test` | Vitest unit tests |
